# 기능 불러오기

1. 인수가 파일이면 `context/features/`에서 정확한 경로 또는 이름으로 찾는다. 수정 기록을 지정했다면 해당 `context/fixes/` 문서를 사용한다. 후보가 여러 개면 임의로 선택하지 않는다.
2. 인수가 자연어 요구사항이면 `context/features/_template.md`를 바탕으로 필요한 만큼의 스펙을 작성한다. 짧은 수정도 최소한 문제·범위·수용 기준·검증 방법을 남긴다. 인수가 없으면 필요한 파일명 또는 설명을 요청한다.
3. 스펙에서 목표·범위·수용 기준을 추출한다. 중요한 미정 사항은 메모에 남기고, 구현을 좌우할 때만 확인한다.
4. `context/current-feature.md`의 현재 작업 영역을 갱신한다. 상태는 `대기`, 스펙은 실제 상대 경로로 기록한다. 기존 완료 이력은 그대로 둔다.
5. 불러온 기능, 수용 기준, 미정 사항을 요약한다. 불러오기만 요청받았다면 구현을 시작하지 않는다.
