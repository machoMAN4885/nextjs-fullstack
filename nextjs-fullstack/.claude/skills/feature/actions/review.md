# 요구사항 검토

스펙의 수용 기준을 현재 코드·설정·검증 근거와 하나씩 대조한다. 시작 시 기록한 변경사항과 Git 차이를 함께 보고 다른 사람의 변경을 이 기능에 포함하지 않는다. `main` 위에서 작업하므로 `git diff main`만으로 전체 변경을 판단하지 않는다. 새 파일도 확인한다.

검토 대상:

- 수용 기준의 충족 여부와 실제 파일 근거
- 빠진 실패 흐름, 입력 검증, 인증·소유권 확인
- Next.js 서버/클라이언트 경계와 비밀값 노출
- DB 제약조건, 마이그레이션, 불필요한 조회
- 스펙 밖 기능, 불필요한 의존성, 문서와 실제 상태의 불일치

아직 만들기로 하지 않은 기능을 결함으로 보고하지 않는다. 추정과 확인한 문제를 구분한다. 검토만 요청받았다면 코드를 수정하지 않는다.

결과는 `수용 기준 / 충족 여부 / 근거 / 남은 작업` 표와 중요한 발견사항으로 보고한다. 현재 기능 상태는 `검토 중`으로 기록하고 완료 가능 여부를 설명한다.
