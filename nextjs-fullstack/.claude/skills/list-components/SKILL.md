# 컴포넌트 목록

이 프로젝트 루트의 `apps/web/src/components/`를 조사한다. 하위 경로 인수가 있으면 그 디렉터리 안으로 범위를 좁힌다. 프로젝트 밖 경로는 탐색하지 않는다.

1. `rg --files`로 `.tsx`, `.jsx`, `.ts`, `.js` 후보를 찾는다. `node_modules`, 생성 파일, 테스트는 제외한다.
2. 내용을 확인해 실제 컴포넌트와 일반 유틸리티를 구분한다. 파일명만으로 기능을 지어내지 않는다.
3. 번호, 프로젝트 상대 경로, 컴포넌트 이름, 한 줄 역할을 한국어로 출력한다. 필요한 경우 서버/클라이언트 경계도 표시한다.
4. 컴포넌트가 들어 있는 파일 수를 요약한다. 한 파일에서 여러 컴포넌트를 내보내면 이를 구분한다.

`apps/web/src/components/`가 없으면 아직 컴포넌트 폴더가 없다고 안내한다. 페이지까지 조사해 달라는 요청이면 `apps/web/src/app/`의 실제 페이지·레이아웃도 별도로 포함한다. 파일이나 폴더를 생성·수정하지 않는다.

```text
$list-components
/list-components dashboard
```
