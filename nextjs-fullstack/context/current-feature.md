# 현재 기능: 없음

## 상태

대기

## 스펙

아직 불러온 기능이 없다. 첫 작업 후보: `context/features/000-project-bootstrap.md`.

## 목표

아직 선택하지 않음.

## 수용 기준

선택한 스펙의 수용 기준을 이곳에서 추적한다.

## 작업 기준점

시작할 때 Git HEAD와 기존 변경 파일을 기록한다. 기존 사용자 변경을 현재 기능 변경으로 오인하지 않는다.

## 검증 결과

제품 구현·테스트 없음. 템플릿 자체의 확인 결과는 `docs/verification.md`에 별도로 기록한다.

## 메모

기능명·상태·스펙·목표·수용 기준·기준점·검증 결과·메모는 현재 작업 영역이다. 다음 기능을 불러올 때 이 부분만 교체한다.

## 완료 이력

아직 완료한 제품 기능이 없다. 이후 기록은 오래된 것부터 최신 순서로 맨 아래에 추가한다. 기존 기록을 삭제하거나 원본 프로젝트의 완료 이력을 가져오지 않는다.
