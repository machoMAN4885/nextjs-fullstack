# 기능 스펙 목록

`prd-to-specs`가 여러 문서·자료 폴더와 선택적 Figma 화면을 분석해 이 목록을 갱신한다. 상세 대응표와 분해 이유는 실행 후 생성되는 `context/spec-plan.md`에 기록한다. 현재는 실제 제품 자료를 제공받아 분석한 상태가 아니며 기술 기반 후보만 있다.

| 순서 | 스펙 ID | 기능 | 스펙 | 선행 스펙·이유 | 상태 |
| --- | --- | --- | --- | --- | --- |
| 0 | 000-project-bootstrap | Next.js 앱과 DB 접근 기반 생성 | [초기화 스펙](features/000-project-bootstrap.md) | 없음 | 대기 |

제품 기능은 원본 자료의 근거에 따라 추가한다. 스펙을 작성한 것과 제품 기능을 구현한 것을 구분하고, 기존 진행 상태와 완료 기록을 보존한다. 로그인·결제·AI 기능을 기본 요구사항으로 넣지 않는다.
